## [1.0.0] - 2026-09-27

### Added
- Initial public release.
- `init`, `add`, `license`, `readme`, `editorconfig`, `contributing`,
  `changelog`, `issue-templates`, `detect` subcommands.
- Ecosystem presets: general, python, node, go, rust, java, docker.
- License templates: MIT, ISC, BSD-2-Clause, Apache-2.0.
- Idempotent writes, `--force`, `--dry-run`, `--non-interactive`.
- Trilingual README (Simplified Chinese / Traditional Chinese / English).
- unittest suite with 35 test cases.
